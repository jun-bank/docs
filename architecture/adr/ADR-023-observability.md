# ADR-023. 관측 — **중앙 관측 · 분산 제어. 규약은 지금, 도구는 나중**

- 일자: 2026-08-06
- 상태: **채택**
- 결정자: 사용자 · AI 페어
- 근거: Phase 5 진입 아키텍처 스케치 v2·v4 · **품질 속성 §2.2 D-05 부분 철회** · 사용자 확정(*"도구는 실제 필요할 때 추가"*)
- 관련: **ADR-005·014**(outbox·릴레이) · **ADR-017**(감사 — 범주가 다르다) · **ADR-021**(전달 경로) · **BR-52·53** · 불일치 **M16·M17·M18** · `interfaces/` **X-5 ④**

---

## 1. 맥락 — 포기했던 것이 절반만 살아 돌아왔다

아키텍처 기술서 §4가 **경고를 남겨 뒀다**:

> ⚠️ *"관찰 방법이 '지표'인 것이 여럿이다. **D-05(실시간 관측)를 포기했으므로 그 지표를 어디서 보는지가 Phase 5의 과제다.**"*

그리고 품질 속성 §2.2가 그 사이에 **D-05를 부분 철회**했다:

| D-05의 상태 | 문면 |
|---|---|
| 원래 근거 | **C-04**(예산 0) · **C-02**(운영 1명) |
| 지금 | ★ **부분 철회** — *"인원이 늘면 관측 도구를 운영할 수 있다. 다만 **탐지가능성은 여전히 대사가 소유**하고, 실시간 관측은 '있으면 좋은 것'으로 내린다"* (`quality-attributes.md` §2.2) |
| 범위 밖(포기가 아닌 것) | **헬스체크·기본 지표**(가용성 채택 — *죽은 것을 알아야 살릴 수 있다*) · **감사 기록**(관측이 아니라 **기록 의무** — ADR-017 기각 D) |

> ★ **"부분 철회"는 "관측 스택을 지금 세운다"가 아니다.** *세울 수 있게 됐다* 는 뜻이고,
> **탐지의 소유자는 여전히 대사**다. 이 선을 안 그으면 관측이 대사의 자리를 침범한다.

### 그런데 지금 안 하면 못 하는 것이 하나 있다

| | 나중에 붙일 수 있나 |
|---|---|
| 수집기·대시보드·경보 | ✅ **언제든** — 이미 노출된 지표를 긁어가면 된다 |
| ★ **추적 문맥(traceparent)의 전파** | ❌ ★ **소급 불가** — outbox 레코드에 컬럼이 없으면 그 레코드는 **영원히 문맥이 없다.** 메시징 구간은 자동 계측이 넘겨주지 않는다 |

**이 비대칭이 이 ADR의 형태를 정한다 — 규약은 지금, 도구는 나중.**

## 2. 결정

| # | 규칙 | 왜 |
|---|---|---|
| **OB-1** | ★ **관측은 중앙, 제어는 분산**이다 — 수집·대시보드·경보는 한곳으로 모으고, **조치(DLQ 재투입·정산 재개·격리 승격)는 각 배포의 기존 정본 조작**이 소유한다. **관측 계층은 쓰기 권한을 갖지 않는다** | 관측이 조작을 하면 **관측 장애가 자금 경로 장애**가 된다. 관측은 보는 것이고, 고치는 것은 소유자다(O-14 — DLQ 재투입은 운영자 조작) |
| **OB-2** | v1의 노출은 둘뿐이다 — ⑴ **구조화 로그**(공통 필드: 시각·배포·경로 식별자·상관 식별자·추적 ID·결과) ⑵ **Micrometer 표준 메트릭 노출**. **수집기·대시보드 제품 선택은 [구현 검증]** — 보유 인프라 재사용을 먼저 검토한다 | 노출은 애플리케이션의 계약이고 수집은 운영의 선택이다. 계약만 지금 고정한다 |
| **OB-3** | ★ **`traceparent` 전파 규약은 공통 층이 소유**한다. ⑴ HTTP 구간 = 표준 헤더 전파 ⑵ ★ **메시징 구간 = outbox 레코드의 컬럼 → 전달 봉투의 헤더 → 수신측 복원**(★ 자동 계측이 못 넘는 구간을 **공통 층이 소유**한다) ⑶ ★ **전문 채널은 헤더가 없다**(X-5 고정길이) — **상관 식별자(X-5 ④)를 추적 태그로 매핑**하고 그 매핑을 어댑터가 기록한다 | 승인 한 건이 채널 → 코어 → outbox → 릴레이 → 위성까지 간다. **한 구간이라도 문맥이 끊기면 그 뒤는 다른 요청과 구별되지 않는다** |
| **OB-4** | ★ **규약은 지금 넣고 도구는 나중에 넣는다** — 컬럼·헤더·필드는 **지금 없으면 소급이 불가**하고(과거 레코드를 채울 방법이 없다), 수집기는 **언제든 붙는다** | *"나중에 관측 붙이면서 같이 하자"* 가 실패하는 유일한 지점이 이것이다 |
| **OB-5** | ★ **조기 신호 3종을 노출**한다 — ⑴ **outbox age**(파티션별 미전달 최대 경과) ⑵ **전달 실패율**(재시도 진입 비율) ⑶ **`DLQ_UNRESOLVED` 건수**. 지표 정의·임계는 **[구현 검증 — IV-13]** | M16·M17은 **영업일 축**의 사후 장치다. *"오늘 밤 커트오프가 막힐 것"* 을 **낮에** 알려주는 신호가 그 앞에 있어야 한다 |
| **OB-6** | ★ **관측은 기존 탐지 장치를 대체하지 않는다** — **M16·M17·M18·BR-53은 그대로**이고 관측은 **그 앞단 신호**다. 불일치의 정본은 대사가, 조치의 정본은 각 조작이 소유한다 | 신호와 판정을 섞으면 *"대시보드가 초록이니 괜찮다"* 가 대사 결과를 이긴다. D-05 부분 철회의 문면(*"탐지가능성은 여전히 대사가 소유"*)이 이 규칙이다 |
| **OB-7** | **관측은 감사가 아니다** — 감사 기록(ADR-017)은 **기록 의무**이고 append-only·보존 기간·변조 방지가 걸린다. 로그·메트릭은 **회전·유실이 정상인 매체**이며 둘을 서로의 대체재로 쓰지 않는다 | ADR-017 기각 D가 이미 판정한 범주 혼동이다. 역방향(감사로 관측을 갈음)도 같은 오류다 |

### 관측 · 탐지 · 감사의 층위 (한 장)

```
관측(이 ADR)   낮에 뜨는 신호      outbox age · 전달 실패율 · DLQ 건수   ← 유실돼도 자금은 무사
탐지(대사)      영업일 축의 판정    M9~M18 · BR-52 커트오프              ← 정본
감사(ADR-017)   기록 의무           C8 append-only · 보존·변조 방지       ← 유실 = 규제 위반
```

> ★ **셋은 강도가 다르다.** 위로 갈수록 싸고 약하며, 아래로 갈수록 비싸고 강하다.
> **약한 것으로 강한 것을 대체하지 않는다**는 것이 OB-6·OB-7의 전부다.

## 3. 왜 나머지를 기각했나

| 안 | 기각 이유 | 이 이유가 바뀌면 (도입 조건) |
|---|---|---|
| **A. APM·분산 추적 수집 스택을 지금 도입** | D-05는 **부분** 철회다 — *"있으면 좋은 것"* 이지 지금의 요구가 아니다. 수집 스택은 그 자체가 운영 대상이고, **규약만 있으면 나중에 붙는다**(OB-4) | ★ **D-05 재검토 조건 그대로 — 장애 원인 분석이 로그로 안 될 때** |
| **B. 추적 규약도 나중에** | ★ **소급이 불가능하다** — outbox 컬럼·봉투 헤더가 없던 기간은 영원히 문맥이 없다. 이것이 A와 B를 가르는 유일한 기준이다 | — (구조적) |
| **C. 배포마다 자기 대시보드** | 관측해야 할 것(**전달 경로**)이 **두 배포에 걸쳐** 있다 — 발신 outbox age와 수신 반영을 한 화면에서 못 보면 진단이 안 된다 | — |
| **D. 감사 기록으로 관측을 갈음** | ADR-017 기각 D의 역방향 — **범주가 다르다**(OB-7). 감사에는 outbox age·지연 같은 운영 신호가 없고, 감사를 운영 지표로 쓰면 **기록 조회가 상시 부하**가 된다 | — |
| **E. 관측 계층이 자동 조치(DLQ 자동 재투입 등)** | ★ **ADR-014 O-14 그대로** — 자동 재투입은 영구 실패에서 무한 루프가 된다. 사람이 원인을 봐야 한다 | — |

## 4. 결과

| | 내용 |
|---|---|
| **얻는 것** | 기술서 §4의 숙제(*"그 지표를 어디서 보는지"*)가 답을 갖는다 · 커트오프 실패를 **낮에** 안다 · 추적 문맥이 **소급 불가 구간에서 확보**된다 |
| **내주는 것** | outbox 레코드에 컬럼이 하나 늘고 봉투가 조금 커진다 · 대시보드는 아직 없다(로그·지표 노출까지) |
| **새로 생기는 일** | ★ **IV-13**(조기 신호 지표·임계) · traceparent 컬럼의 스키마 변경(ADR-015 expand-contract) · 전문 채널의 `correlationId ↔ traceId` 매핑 기록 |

## 5. 되돌리는 조건

| # | 관찰되면 | 그때 할 일 |
|---|---|---|
| **R1** | ★ **조기 신호가 M16·M17보다 늦게 뜬다** | 신호가 아니라 후행 지표다 — 임계·수집 주기를 IV-13으로 재산정 |
| **R2** | 로그만으로 **장애 원인 분석이 반복 실패**한다 | **D-05 전면 철회** — 안 A(수집 스택) 도입. 이것이 D-05가 스스로 적어 둔 조건이다 |
| **R3** | 관측 수집이 **자금 경로 지연에 잡힌다**(QS-01·QS-06) | 노출을 비동기·샘플링으로 — **수집 때문에 자금 경로가 느려지면 관측이 아니다** |
| **R4** | traceparent 전파가 **outbox 레코드·봉투 크기를 유의미하게** 키운다 | 문맥을 참조 키로 축약(전체 문맥은 수집기 쪽에) |
| **R5** | ★ **대시보드가 초록인데 대사가 불일치를 낸다** | OB-6이 무너진 신호 — 신호를 판정으로 쓰고 있지 않은지 절차를 점검한다 |

## 6. 검증

| 언제 | 무엇으로 | 통과 기준 |
|---|---|---|
| Phase 5 | ★ **문맥 연속성** | 승인 1건이 **채널 → 코어 → outbox → 릴레이 → 위성 반영**까지 **하나의 추적 ID**로 이어진다 |
| Phase 5 | 전문 채널 매핑 | 고정길이 전문 1건의 **상관 식별자로 그 요청의 추적을 찾을 수 있다**(OB-3 ⑶) |
| Phase 5 | ★ **조기 신호 발화** | 릴레이를 정지시킨다 → **outbox age가 오른다**. 그리고 **커트오프 실패(M16)보다 먼저** 뜬다 |
| Phase 5 | 독립성 | 수집기를 중단시킨다 → **자금 경로·대사 결과에 영향 없음**(OB-1) |
| Phase 5 | 층위 | 관측 계층 계정에 **쓰기 권한이 없다**(OB-1 · ADR-022 권한 매트릭스) |
