# UC-09. 응답 유실 승인을 망취소한다

- 작성일: 2026-08-05
- 상태: **초안 (계약 블록 후속)**
- 액터: **매입사/VAN** (시스템 주체 — R1 전문 경로. ★ **대리가 아니라 자기 목표다**: 응답을 받지 못해 성패를 모르는 거래를 강제로 정리해 **양측 장부를 일치**시킨다)
- 권한 요건: 시스템 주체 — BR-54 예외 목록 밖(단건 원거래 지목). 운영자 단계 무관 · BR-56 승인 대상 아님
- 트랜잭션 경계: **E1**(원승인 발견 시 — 승인·계좌·카드) / **경계 없음**(원승인 미발견 시 — 취소 예약 `record`는 자기 애그리게이트만 변경한다. 자금 무이동이라 E1~E5 분류 기준 밖 — 조작 대장)
- 관련 규칙: BR-01·02·13·17·22·24·26·33·44·49·54·57 · 승인 T4·T13 · 예약 R1·R2·R3·R4 (참조만 — F-24)

## 1. 목표 (한 문장)

매입사가 **응답을 받지 못한 승인 요청**에 대해 망취소 전문을 보내, 원 승인이 성립했으면 무효화하고 **아직 도착하지 않았으면 뒤늦게 도착할 승인까지 무효화되도록 예약**한다 — 몇 번 보내든 최종 상태는 같다.

## 2. 사전 조건 / 사후 조건

- 사전: 망취소는 **상관 식별자만으로** 원거래를 식별한다 — 승인 응답이 유실됐으므로 매입사는 승인번호를 모른다(BR-17 ①).
- 사후(성립 건): `VOIDED` · 홀딩 해제 · 두 층 한도 복원 — 한 커밋(T4 · E1).
- 사후(만료 건): `VOIDED` + **채무 소멸**. 홀딩·한도는 만료가 이미 복원했으므로 **재복원하지 않는다**(T13 · BR-49).
- 사후(거절·이미 무효 건): **무변화. 오류가 아니다** — BR-13의 *"성립하지 않았다면 상태 변화가 없다"* 에 해당한다.
- 사후(원승인 미발견): 취소 예약 `PENDING`, `expiresAt = 수신 + 1시간`(확정 수치 — BR-22). 이후 도착한 동일 원승인은 **홀딩을 만들지 않고** `VOIDED`로 생성되며 예약이 소비된다(승인 T3 · E1).
- 사후(매입 후): 거절 — 자금·상태 무변화. 매입사는 환불(취소 레코드) 경로로 가야 한다.
- 사후(예약 미사용): TTL 경과 후 레코드 삭제(`ABSENT`) — **실패가 아니라 정상 결말**이다(승인 전문이 아예 도달하지 않은 경우).

## 3. 주요 성공 시나리오

1. 망취소 전문 수신 → R1 ACL 번역 + **경로 식별자 부여** [BR-33 실시간 전문 · BR-54]
2. **상관 식별자**로 원승인 조회 [BR-17 ①]
3. 발견 → `reverse()` — 상태별 분기: `AUTHORIZED` → T4 · `EXPIRED` → T13 · `DECLINED`·`VOIDED` → `◎`(무변화)
4. 복원은 **`holdingFunds`가 참일 때만** — `Account.releaseHold` · `Card.restoreLimit` · `Account.restoreAccountLimit` [BR-24·44 · 이중 복원 차단]
5. [E1 커밋] 승인·계좌·카드 + 감사 outbox
6. 미발견 → `ReversalTombstone.record(correlationId, at, ttl)` — `PENDING` 생성 [BR-22 · R1]
7. 응답 송신 (예산은 **[미검증]** — BR-01은 승인 응답 규칙이다, §9)
8. (후속·별도 흐름) 뒤늦은 승인 도착 → 유효한 예약 확인 → `createVoidedByTombstone` + `consume` **한 커밋** [승인 T3 · 예약 R2 · E1]

## 4. 예외 시나리오 ★

| # | 트리거 | 시스템 반응 → 종결 | 근거 |
|---|---|---|---|
| A | **중복 망취소**(성립 건) | 2회차부터 **무변화** — 최종 상태 동일 | BR-13 · 매트릭스 `VOIDED`/`reverse` = ◎ |
| B | **거절된 승인**에 망취소 | **무변화 — 오류가 아니다.** 거절 건에 망취소가 오는 것은 성립 건만큼 정상이다 | BR-13 예외 · 매트릭스 `DECLINED`/`reverse` = ◎ |
| C | 원승인이 **매입됨**(`CAPTURED`) | 거절 `AUTH_ALREADY_CAPTURED` — 망취소는 **응답 유실에 대한 조치**이지 확정 거래의 취소 수단이 아니다. 무효화하면 매입사엔 매입·우리에겐 무효로 **영구 불일치** | **F1** |
| D | 원승인이 **정산완료**(`SETTLED`) | 거절 `AUTH_ALREADY_SETTLED` — 순액이 확정·지급됐다 | **F2** · BR-47 |
| E | 원승인이 **환불완료**(`REFUNDED`) | 거절 — 전액 환불로 잔여 채권이 0 | F4 |
| F | **원승인 미발견** | 거절이 아니라 **취소 예약 기록**(`PENDING`) — 뒤늦게 올 승인을 미리 죽인다 | BR-22 · 예약 R1 |
| G | 중복 망취소가 **선도착 상황**에서 옴 (유효한 예약이 이미 있음) | 새 예약을 만들지 않고 **무시**(◎) — 오류로 만들면 정상 경로가 막힌다 | RF3 · 예약 INV-1 |
| H | **만료 시각은 지났는데 정리 배치 전**인 예약에 새 망취소 | ★ **새 예약으로 대체**한다 — `◎`로 버리면 새 취소 의사가 조용히 사라지고, 직후 정리 배치가 삭제하면 뒤늦은 승인을 막을 것이 없어진다 | 예약 §0 · 매트릭스 `PENDING`/`record` 조건부 |
| I | 이미 소비된 예약으로 **재소비** 시도 | 거절 `TOMBSTONE_CONSUMED` — **한 예약은 한 승인만** 무효화한다. 아니면 재전송된 정상 승인까지 죽는다 | **RF1** · 예약 INV-3 |
| J | 만료 시각이 지난 예약으로 소비 시도 | 거절 `TOMBSTONE_EXPIRED` — `consume()`이 **시각을 직접 판정**한다(정리 배치를 믿지 않는다) | **RF2** · 예약 §0 |
| K | TTL 안에 원승인이 오지 않음 | `expire` — 레코드 삭제 → `ABSENT`. **정상 결말**이며, 이후 같은 상관 식별자의 망취소는 새 예약을 만든다 | 예약 R3 · SM §1 |
| L | **TTL 경계 경합** — 만료가 근소하게 이김 | 그 승인이 **예약 없이 정상 성립**한다. 사후에는 대사 M1(미매입)로만 나타난다 — 구조적 해법이 없는 잔여 위험 | RTS2 · RT3 · 예약 §6 |
| M | 보류(`frozen = true`) 중인 승인에 망취소 | **통과한다** — 보류는 `expire`·`capture`만 막는다. `frozen`인 채 `VOIDED`에 도달하므로 종료 상태의 `unfreeze`가 목록에서 내리는 유일한 경로다 | F17 범위 · F9 주석 · BR-28 |
| N | 예약 소비와 만료 배치의 경합 | 애그리게이트 락 — `consume`이 이기면 `CONSUMED`(만료 대상에서 빠짐), `expire`가 이기면 §4-L | 예약 §6 |

## 5. 대체 시나리오

- 없음 — 망취소의 경로는 하나다. 원승인 유무에 따른 두 갈래(§3-3·§3-6)는 **같은 목표의 분기**이지 다른 경로가 아니다. 매입 후에는 목표 자체가 환불로 바뀌므로 별도 유스케이스다(UC-11). *(U-6: "해당 없음" 근거)*

## 6. 인가·감사 ★

- 주체 판정: R1 ACL 진입 시 1회(AU-3·AU-4) — 시스템 주체 + 경로 식별자. **소유자 필터 없음**(AU-2). 원승인 미발견 시에도 주체 기록은 예약에 붙는 경로 정보로 남는다.
- L7: ✕ **대상 아님** — C-2 채널 조항(사람 주체 API 한정). ★ 다만 이 유스케이스에서는 **"원승인 없음"이 거절 사유가 아니다** — 예약으로 흡수되므로 존재 여부가 응답으로 새지 않는다. 거절은 §4-C·D·E뿐이며, 매입사가 후속 조치(환불 레코드 전환·대사 조회)를 고르려면 셋이 구분돼야 한다.
- 감사: 성공 = E1 커밋 내 outbox(AD-2) · **예약 기록도 남는다** — 자금은 안 움직이지만 BR-57의 적용 범위가 *"시스템 주체(배치·전문·릴레이)의 실행 포함"* 이다 · 거절(§4-C·D·E) = **독립 커밋**. 항목은 AD-8.
