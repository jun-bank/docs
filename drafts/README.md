# drafts — 선행 조건 미충족 문서

여기 있는 문서는 **내용이 틀려서가 아니라, 워크플로 순서를 앞질러 작성되어** 격리된 것이다.

`study/project-workflow/README.md`의 원칙:

> **각 단계는 이전 단계의 산출물을 입력으로 받는다. 입력이 비어 있으면 그 단계는 아직 시작할 수 없다.**

아래 문서들은 이 원칙을 어겼다. 내용 자체는 재사용 가치가 있으나, **확정된 것으로 읽히면 안 된다.**

## 복귀 절차

1. 복귀 조건이 충족되면 **처음부터 다시 쓰지 않는다.** 이 문서를 열고 **선행 산출물에 비추어 검증**한다
2. 어긋난 부분을 고친다 (특히 추정으로 채운 곳)
3. 정규 경로로 옮긴다
4. 상태를 `초안` → `확정`으로 바꾼다

## 읽을 때 주의

- **여기 있는 판단을 근거로 인용하지 않는다.** 특히 `03-transaction-design.md`의 흐름별 배정과 `c4-model.md`의 컨테이너 구성은 **추정이 섞여 있다**
- 다른 문서에서 이곳을 참조하는 링크는 `drafts/` 경로로 되어 있다. 그 자체가 "아직 확정 아님"의 표시다
